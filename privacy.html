隱私權政策

適用對象：Chrome 外掛「每日日曆與自動提醒」（以下簡稱「本外掛」）
生效日期：2026-11-19

1. 本外掛處理哪些資料

本外掛處理的資料都是使用者自己輸入或設定的內容：

  • 待辦事項：事項文字、所屬日期、提醒時間（選填）、是否完成、是否已通知與通知時間、建立與修改時間。
  • 設定：每日總提醒時間、自動清除的開關與天數。
  • 刪除紀錄：為了讓多台電腦同步時不會把已刪除的事項加回來，本外掛會保留刪除紀錄（事項 id、日期、刪除時間），保留 30 天。

本外掛不讀取使用者的電子郵件、姓名、聯絡人、雲端硬碟內的其他檔案，也不讀取瀏覽紀錄或網頁內容。

2. 使用目的

這些資料只用來提供外掛本身的功能：顯示月曆與待辦事項、依設定時間發出提醒通知，以及在使用者自己的多台電腦之間同步待辦事項與設定。

3. 資料存放位置

位置內容說明
使用者的瀏覽器本機（chrome.storage.local）全部資料外掛運作的主要資料，一律存在這裡。
Chrome 同步（chrome.storage.sync）設定、刪除紀錄、事項（容量有限時只放較近的日期）預設開啟，可在外掛設定關閉。資料由 Chrome 存放在使用者自己的 Google 帳號；Chrome 本身是否有開同步，由使用者在 Chrome 設定控制。
使用者自己 Google 雲端硬碟的應用程式專屬資料夾（appDataFolder）一個檔案 calendar-data.json，內容為全部事項、刪除紀錄與設定預設關閉，使用者按「登入 Google」授權後才開啟。此資料夾只有本外掛讀寫得到，使用者在雲端硬碟畫面上看不到；本外掛無法讀取雲端硬碟中的其他檔案。

另外，使用者可以自行把資料匯出成 JSON 檔，該檔案存在使用者自己選擇的位置，由使用者自行保管。

4. 開發者不蒐集資料

  • 開發者沒有自己的伺服器，本外掛不會把資料傳送到開發者或任何第三方的伺服器。
  • 本外掛唯一連線的對象是 Google：用於 Google 雲端硬碟 API（www.googleapis.com）讀寫上述資料檔，以及登出時向 Google 撤銷授權（oauth2.googleapis.com）。這些連線只在使用者開啟並登入雲端硬碟同步後發生。Chrome 內建同步則由 Chrome 自行處理。
  • 不蒐集、不販售、不出租資料，也不提供給第三方。
  • 資料不用於廣告、行銷、使用者輪廓分析或信用評估。
  • 本外掛沒有分析、追蹤或廣告程式碼，也不使用 Cookie。

5. Google 權限範圍與有限使用（Limited Use）聲明

本外掛只要求一個 Google OAuth 範圍：https://www.googleapis.com/auth/drive.appdata（檢視及管理本外掛自己在雲端硬碟中的應用程式專屬資料）。此範圍不能存取使用者雲端硬碟中的其他檔案。

本外掛使用及轉移從 Google API 取得的資訊時，會遵守 Google API Services User Data Policy（Google API 服務使用者資料政策），包含有限使用（Limited Use）要求。具體來說：

  • 從 Google API 取得的資料只用於提供與改善使用者在外掛中看得到的功能（跨裝置同步待辦事項）。
  • 不會把這些資料轉移給第三方，除非是為了提供上述功能。
  • 不會把這些資料用於廣告，包含再行銷、個人化或興趣導向廣告。
  • 不會讓人員讀取這些資料。開發者沒有伺服器，無法取得使用者存放在自己雲端硬碟的資料。

6. 使用者如何刪除資料與撤銷授權

以下畫面用語可能因版本不同而有出入，請以實際畫面為準。

  • 刪除本機資料：在 chrome://extensions 移除本外掛，Chrome 會一併移除外掛存放在瀏覽器裡的資料；也可以在外掛內刪除單筆事項，或使用自動清除。
  • 停止雲端硬碟同步：在外掛設定的「Google 雲端硬碟」按「登出」。登出會清除這台電腦保存的授權並嘗試向 Google 撤銷；雲端上的 calendar-data.json 會保留，不會因登出而刪除。
  • 撤銷授權：到 Google 帳戶的「第三方應用程式與服務」（third-party apps & services）存取權頁面，找到本外掛並移除存取權。
  • 刪除雲端硬碟中的資料檔：到 Google 雲端硬碟設定的「管理應用程式」（Manage apps），找到本外掛，選擇刪除隱藏的應用程式資料。
  • Chrome 同步的資料：由 Chrome 儲存在使用者的 Google 帳號，可在 Chrome 的同步設定管理，或在外掛設定關閉「跨裝置同步」。

7. 資料保留

資料保留多久由使用者自己控制。本外掛預設開啟「自動清除」：已通知或已完成的事項，滿設定天數（預設 7 天，可設 1 到 365 天）後自動刪除；使用者可以關閉自動清除，也可以隨時手動刪除事項。未完成且從未通知過的事項不會被自動刪除。刪除紀錄保留 30 天後移除。雲端硬碟上的資料檔會一直保留，直到使用者依第 6 節自行刪除。

8. 兒童

本外掛不是針對兒童設計，也不會刻意蒐集兒童的資料。

9. 政策變更

如果本政策有修改，會更新本頁內容並更改上方的生效日期。

Privacy Policy

Applies to: the Chrome extension "每日日曆與自動提醒" (Daily Calendar and Auto Reminders) (the "Extension")
Effective date: 2026-11-19

1. Data the Extension handles

All data handled by the Extension is content that the user enters or configures:

  • To-do items: item text, date, optional reminder time, completion status, notification status and time, and creation and modification times.
  • Settings: the daily reminder time, and the auto-clean switch and number of days.
  • Deletion records: so that deleted items are not added back when several computers sync, the Extension keeps deletion records (item id, date, deletion time) for 30 days.

The Extension does not read the user's email address, name, contacts, other files in Google Drive, browsing history or web page content.

2. Purpose

The data is used only to provide the Extension's own functions: showing the calendar and to-do items, sending reminder notifications at the configured times, and syncing to-do items and settings between the user's own computers.

3. Where data is stored

The user can also export the data to a JSON file. That file is saved at a location the user chooses and is kept by the user.

4. The developer does not collect data

  • The developer runs no server. The Extension does not send data to the developer or to any third-party server.
  • The only party the Extension connects to is Google: the Google Drive API (www.googleapis.com) to read and write the data file described above, and Google's endpoint (oauth2.googleapis.com) to revoke authorization when the user signs out. These connections happen only after the user turns on Google Drive sync and signs in. Chrome Sync is handled by Chrome itself.
  • Data is not collected, sold or rented, and is not provided to third parties.
  • Data is not used for advertising, marketing, user profiling or credit evaluation.
  • The Extension contains no analytics, tracking or advertising code and does not use cookies.

5. Google OAuth scope and Limited Use disclosure

The Extension requests a single Google OAuth scope: https://www.googleapis.com/auth/drive.appdata (view and manage the Extension's own application data in Google Drive). This scope does not allow access to any other file in the user's Google Drive.

The Extension's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Specifically:

  • Data obtained from Google APIs is used only to provide the user-facing features of the Extension (syncing to-do items across the user's computers).
  • The data is not transferred to third parties except as needed to provide those features.
  • The data is not used for advertising, including retargeting, personalized or interest-based advertising.
  • No humans read the data. The developer has no server and cannot access data the user stores in their own Google Drive.

6. How to delete data and revoke access

Wording on screen may differ between versions; follow what is actually shown.

  • Local data: remove the Extension at chrome://extensions; Chrome also removes the data the Extension keeps in the browser. You can also delete individual items inside the Extension, or use auto-clean.
  • Stop Google Drive sync: in the Extension's settings, under "Google Drive" (Google 雲端硬碟), click the sign-out button (登出). Signing out clears the authorization held on this computer and attempts to revoke it with Google. The calendar-data.json file in Google Drive is kept and is not deleted by signing out.
  • Revoke access: open the third-party apps & services access page of your Google Account, find the Extension, and remove its access.
  • Delete the data file in Google Drive: open "Manage apps" in Google Drive settings, find the Extension, and choose to delete the hidden app data.
  • Chrome Sync data: stored by Chrome in the user's Google account; manage it in Chrome's sync settings, or turn off "cross-device sync" in the Extension's settings.

7. Data retention

The user controls how long data is kept. Auto-clean is on by default: items that have been notified or marked done are deleted after the configured number of days (default 7, configurable from 1 to 365). The user can turn auto-clean off and can delete items manually at any time. Items that are incomplete and have never been notified are not deleted automatically. Deletion records are removed after 30 days. The data file in Google Drive is kept until the user deletes it as described in section 6.

8. Children

The Extension is not designed for children and does not knowingly collect data from children.

9. Changes to this policy

If this policy changes, this page will be updated and the effective date above will be changed.
